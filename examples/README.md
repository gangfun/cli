# Examples

Small programs built on the `gang` CLI and the public API. Copy them, change them, ship your own.

| Example | What it does | Sends transactions? |
|---|---|---|
| [mcp-agent](mcp-agent/) | A template for a trading assistant: Claude uses `gang mcp`, and you approve every send | Mainnet, only after you type the code it shows |
| [testnet-first-trade](testnet-first-trade/) | Creates a token, buys and sells it on BSC testnet with a throwaway wallet | Testnet only |
| [watch-telegram](watch-telegram/) | Posts new tokens, near-graduation tokens and graduations to a Telegram chat | No |
| [risk-check](risk-check/) | Lists what to look at before a trade: tax, holders, creator's holding and history | No |

Start with [DEVELOPERS.md](../DEVELOPERS.md). These examples are not investment advice, and their output can be incomplete.
